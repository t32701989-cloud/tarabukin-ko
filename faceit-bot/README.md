# SO2 Arena — бот + Mini App для матчей Standoff 2 с друзьями

Своя ELO-площадка для компании друзей: собираете лобби, бот делит команды по ELO, после игры хост вписывает результат, у всех меняется ELO и уровень (1–10).

## Возможности
**Mini App** (кнопка «Играть» в боте):
- регистрация: ник и ID в Standoff 2, старт с 1000 ELO;
- лобби **5x5** и **2x2**, выбор карты или случайная;
- хост может кикать игроков, указать код или пароль комнаты в игре (его видят только участники), стартовать и отменять матч;
- **автобаланс команд по ELO** при старте;
- ввод результата: победитель и счёт, ELO считается по средним ELO команд (при равных командах ±25);
- рейтинг игроков, профиль с прогрессом до следующего уровня, история матчей.

**Бот** в личке:
- присылает составы и комнату при старте;
- присылает ±ELO и новый уровень после матча;
- команды `/top`, `/me`, `/id`.

Если указать `NOTIFY_CHAT_ID`, бот будет писать в группу друзей о новых лобби и результатах.

## Запуск
Mini App работает только по **HTTPS**, поэтому нужен сервер с публичным адресом.

```bash
cd faceit-bot
pip install -r requirements.txt
cp .env.example .env      # BOT_TOKEN, WEBAPP_URL, ADMIN_IDS
python bot.py             # бот + веб-сервер на порту 8080
```

Варианты, как получить HTTPS-адрес:
- **VPS + домен + Caddy:** `your-domain.com { reverse_proxy localhost:8080 }`, сертификат Caddy выпустит сам.
- **VPS без домена:** `cloudflared tunnel --url http://localhost:8080` выдаст адрес `https://….trycloudflare.com`. Его нужно вписать в `WEBAPP_URL` и перезапустить бота. Адрес меняется при каждом перезапуске туннеля, поэтому подходит для теста.
- **Docker:** `docker build -t so2arena . && docker run -d --env-file .env -p 8080:8080 -v so2data:/data so2arena`.

База хранится в SQLite (`bot.db`). Не теряй её при переезде, там весь рейтинг.

## Локальная разработка без Telegram
`DEV_MODE=1 python bot.py`, потом открыть `http://localhost:8080/?dev=123`. Можно войти как любой пользователь. **Не включай DEV_MODE на сервере.**
