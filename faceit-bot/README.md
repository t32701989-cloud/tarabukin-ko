# SO2 Arena: бот и Mini App для матчей Standoff 2 с друзьями

Своя ELO-площадка в стиле FACEIT. Работает бесплатно на **Cloudflare Workers**, данные хранятся в Durable Object со встроенной SQLite.

## Что умеет
- **Регистрация:** ник и ID в Standoff 2.
- **Калибровка:** первые 10 матчей уровень и ELO скрыты, ELO меняется ×2. После 10-го матча выдаётся уровень.
- **Уровни 1–10** с цветами как на FACEIT:
  - 1 — серый;
  - 2–3 — зелёный;
  - 4–7 — жёлтый;
  - 8–9 — оранжевый;
  - 10 — красный.
- **Постоянные лобби** «Лобби 1» и «Лобби 2» на 5x5: игроки просто заходят. Как только лобби заполнилось, на его месте сразу появляется новое пустое.
- **Когда набралось 10 игроков:**
  - случайно выбираются **2 капитана**, команды делятся по ELO, капитаны попадают в разные команды;
  - капитаны по очереди **банят карты**: 6 банов из 7, последняя карта играется. На бан даётся 45 секунд, потом случайный автобан;
  - случайно выбирается игрок, который **создаёт лобби в игре**. Его ник и игровой ID видны всем, он вписывает код комнаты, и бот рассылает его всем 10 игрокам.
- **Результат** вносит капитан, отменить матч может капитан или админ.
- **Карты:** Sandstone, Rust, Province, Hanami, Prison, Dune, Breeze.
- **База игроков** с поиском: рейтинг откалиброванных и отдельный список тех, кто на калибровке.
- **Профиль** с прогрессом до следующего уровня и историей матчей.
- **Бот пишет в личку:** составы, комнату, итог матча, ±ELO, новый уровень и окончание калибровки. Команды `/top`, `/me`, `/id`.

## Деплой
```bash
pip install -r requirements.txt
cp .env.example .env          # BOT_TOKEN, ADMIN_IDS
CLOUDFLARE_API_TOKEN=... python cloudflare/deploy.py
```
Необязательная переменная `LOBBY_COUNT` (по умолчанию 2) задаёт число постоянных лобби. Её можно добавить в bindings в `deploy.py`.
Токен Cloudflare создаётся по шаблону **Edit Cloudflare Workers**. Скрипт заливает Worker вместе с `webapp/index.html` и настраивает webhook, команды и кнопку «Играть» в Telegram. Повторный запуск обновляет бота, данные сохраняются.

## Файлы
- `cloudflare/worker.js` — API, логика ELO и калибровки, webhook бота.
- `webapp/index.html` — Mini App.
- `cloudflare/deploy.py` — деплой через Cloudflare API.
