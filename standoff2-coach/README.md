# Standoff Coach (Godot 4.2)

Симулятор карьеры тренера киберспортивной команды по Standoff 2.

## Запуск
1. Установите Godot 4.2+ (стандартная версия, не .NET).
2. Импортируйте папку `standoff2-coach` (файл `project.godot`) и нажмите F5.

## Геймплей
- Новая карьера: создание менеджера (имя, возраст, страна, предыстория с бонусами, внешность из вариаций или своё фото из файла), затем выбор команды.
- Ведёте команду из 5 игроков + скамейка через сезоны: Открытая лига → Про-лига → Мировая серия.
- Сезон: 7 туров лиги (BO1), полуфиналы и финал плей-офф (BO3), межсезонье.
- Матч идёт по раундам (MR12 + овертайм, смена сторон, экономика: пистолетки/эко/форс/фулл-бай). Вы выбираете карту, стиль игры и берёте тайм-ауты.
- Менеджмент: тренировки (аим/мышление/сыгранность/карты/отдых), трансферы, состав и роли, зарплаты и спонсоры, навыки тренера.
- Цели совета директоров: топ-4 → топ-6 → топ-8. Два провала подряд или банкротство — увольнение. Выиграйте Мировую серию, чтобы стать легендой.
- Автосохранение после каждой недели (`user://coach_save.json`).

## Языки
Русский и английский (Настройки → Язык). Переводы: `scripts/i18n.gd`.

## Структура
- `scripts/game_state.gd` — автозагрузка: данные карьеры, лига, финансы, сохранения.
- `scripts/match_sim.gd` — симулятор карты.
- `scripts/main.gd` — весь UI, строится кодом.
- `scripts/avatar.gd` — процедурный аватар менеджера / фото.
- `scripts/teams.gd` — стартовые команды и предыстории (список команд временный).
- `scripts/settings.gd` — настройки.
